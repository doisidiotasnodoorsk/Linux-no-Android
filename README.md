# Linux-no-Android
Linux no Android usando apenas o Termux⭐

Ativeas Opções de Desenvolvedor, e ative mais de 2(dois) processos.

Para iniciar o processo, primeiramente instale o Termux no F-Droid:

link:https://f-droid.org/repo/com.termux_1021.apk

O download iniciará automaticamente.

Inicie o Termux no seu celular📱

No Termux, digite: termux-setup-storage
